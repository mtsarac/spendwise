# Spendwise || WIP!!!!

A personal finance management app to track your expenses and income.

## Features

- Add, edit, and delete expenses and income entries.
- Categorize transactions (e.g., Food, Rent, Entertainment).
- View transaction history.
- Generate reports and visualizations of your spending habits.
- Set budgets and receive alerts when nearing limits.
- Export data to CSV for further analysis.
- User authentication and data security.
- Responsive design for mobile and desktop use.
- Multi-currency support.
- Cloud sync to access your data across multiple devices.
- Recurring transactions for regular expenses and income.
- Dark mode for better usability in low-light conditions.

## Technologies Used

- Next.js
- React
- Node.js
- Express.js
- PostgreSQL
